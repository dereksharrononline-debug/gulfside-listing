# Gulfside Listing Presentation

Offline-capable PWA for Derek Sharon · Gulfside Property Group · Real Broker LLC.

Live: https://list.gulfsideholdings.com

## Install on iPad / Android
1. Open the URL above in Safari (iPad) or Chrome (Android).
2. Tap **Share** → **Add to Home Screen**.
3. The "Gulfside Listing" icon will appear on your home screen.
4. Open from the home screen — works fullscreen, works offline.
